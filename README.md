## Description

A tiny, pure-stdlib Python program for the "Weirdest Job Title: Blind
Judge Showdown" bounty on make.fun. Titles are compared pairwise on
which is weirder and funnier, so this entry leans on a familiar truth:
a perfectly real-sounding corporate title, ruined by one hilariously
specific duty that everyone in an office has quietly lived through.

No version of the file is ever really final — and somebody has to be
in charge of renaming it, one desperate suffix at a time.

## Entry title

Director of Renaming Files to final_v2_REAL_final.xlsx

## How it works

Running `main.py` writes that single title, on one line and nothing
else, to `entry.txt` in the directory named by the
`MAKEFUN_OUTPUT_DIR` environment variable (default `/output`),
creating the directory if needed and setting the file mode to 0644.
